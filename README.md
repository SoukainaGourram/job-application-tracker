
# JobTrack

JobTrack is a full-stack web application designed to help users organize and track their job applications throughout the recruitment process.

## Features

- 🔐 User authentication with JWT
- 🏢 Company management
- 💼 Job offer management
- 📋 Application tracking
- 📊 Kanban pipeline for applications
- 🕒 Application history
- 📅 Interview management
- 👤 Company contacts management
- 🔒 User data isolation

## Technologies

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- REST API

### Frontend
- Angular
- TypeScript
- Angular Material

### DevOps
- Docker
- Docker Compose
- GitHub Actions

## Architecture

JobTrack follows a client-server architecture:

- **Frontend:** Angular application
- **Backend:** Spring Boot REST API
- **Database:** PostgreSQL
